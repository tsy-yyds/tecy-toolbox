常见问题

安装版和绿色版有什么区别？

安装版（installer.exe）双击安装、写入开始菜单与快捷方式；绿色版（zip）解压即用、不写注册表。功能完全一样。

被 Windows 拦截 / 报毒了？

个人开发者程序未购买代码签名证书，SmartScreen 属正常拦截：点「更多信息」→「仍要运行」。下载类工具可能被个别安全软件误报，源码在 GitHub 可自查，介意可只用绿色版。

下载工具能下哪些平台？

支持常见音乐平台与短视频平台的链接解析下载（无水印）。具体以程序内说明为准，接口失效会随版本更新修复。

源码在哪里？

全部源码开源在 github.com/tsy-yyds/tecy-toolbox，主程序 main.py，工具模块在 tools/ 目录。

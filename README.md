# 🛠️ 多功能实用工具箱 v2.1

一站式解决日常小需求的桌面工具箱，基于 Python + CustomTkinter 开发，界面美观，功能实用。

## ✨ 功能列表

### 📝 文件批量重命名
- 自定义前缀、起始编号、编号位数
- 按文件类型筛选
- 实时预览重命名效果
- 安全重命名机制，避免文件覆盖

### 🖼️ 图片格式转换
- 支持 JPG / PNG / WEBP / BMP / GIF / ICO 互转
- 质量调节滑块（10-100%）
- 批量添加文件
- 自定义输出文件夹

### 📱 二维码生成器
- 任意内容生成二维码
- 自定义大小（200-800px）
- 4级容错率
- 自定义前景色/背景色
- 实时预览

### 📐 单位换算器
- 8大类单位：长度、重量、面积、体积、温度、时间、速度、数据存储
- 实时换算
- 一键交换单位
- 内置常用换算参考表

### 🍅 番茄钟
- 专注模式（默认25分钟）
- 短休息（5分钟）、长休息（15分钟）
- 自定义时长设置
- 今日统计（番茄数、专注时长）
- 每4个番茄自动切换长休息

### 💻 系统信息查看
- 系统信息、CPU、内存、磁盘、网络
- 运行时间统计
- 实时监控模式（每2秒刷新）

### 🎵 音乐 & 视频下载器
- 汽水音乐解析下载
- 抖音/快手/B站等短视频无水印下载
- 多线程下载，不卡UI
- 实时日志输出

### 📄 PDF 全能工具箱
- 🔗 合并PDF：多文件合并
- ✂️ 拆分PDF：按页码范围拆分
- 📝 提取文本：一键提取所有页面文字
- 🖼️ PDF转图片：2倍高清渲染，每页PNG
- 📄 PDF转Word：转换为可编辑docx文档

## 🚀 快速开始

### 方式一：直接启动（推荐）
双击 `启动工具箱.bat` 即可运行。

### 方式二：全新安装
1. 确保电脑已安装 Python 3.10+
2. 双击运行 `安装.bat`，自动创建虚拟环境并安装依赖
3. 安装完成后双击 `启动工具箱.bat`


- 支持明暗主题一键切换

- 8大功能标签页，切换流畅
- 底部状态栏实时提示

## 🔄 关于自动更新

自动更新功能默认关闭。如需启用：
1. 编辑 `tools/auto_updater.py`
2. 将 `ENABLE_AUTO_UPDATE` 改为 `True`
3. 填入你的123云盘直链地址
